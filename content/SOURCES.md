# Sources de vérification factuelle — Massalia

Ce registre documente les sources institutionnelles et muséales consultées pour relire les dix dossiers historiques du site. Les corrections ont privilégié les sources publiques de référence, en distinguant les données archéologiques établies, les chronologies documentées et les traditions ou récits de fondation.
